# ⚡ Vanilla JavaScript Mini Projects Showcase

A curated collection of practical mini-applications and challenges built using pure **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**. This repository highlights core DOM manipulation techniques, asynchronous timers, and interactive web elements.

---

## 🚀 Projects Overview

| #   | Project Name                                  | Description                                      | Key JavaScript Concepts                                              |
| --- | --------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| 01  | **[Calculator](./calculator/)**               | Interactive arithmetic calculator                | Functions, Event Listeners, String Evaluation / Math Logic           |
| 02  | **[Digital Clock](./digital-clock/)**         | Real-time digital clock display                  | `Date` Object, `setInterval`, Time Formatting                        |
| 03  | **[Stopwatch](./stopwatch/)**                 | Precise stopwatch with start/pause/reset         | `setInterval`, `clearInterval`, State Management                     |
| 04  | **[Form Validation](./form-validation/)**     | Interactive form inputs with instant feedback    | Form Events, Regex / Input Checks, DOM Error Handling                |
| 05  | **[Responsive Navbar](./responsive-navbar/)** | Mobile-friendly navigation toggle                | DOM Class Manipulation (`classList.toggle`), Layout Events           |
| 06  | **[To-Do List](./todo-list/)**                | Task management application with CRUD operations | Array Manipulation, DOM Creation (`createElement`), Event Delegation |

---

## 🛠️ Built With

- **HTML5:** Clean and semantic structure.
- **CSS3:** Modern styling, Flexbox, and CSS Transitions.
- **Vanilla JavaScript (ES6+):** Pure logic without third-party frameworks.
